# Concepts

> Shared domain vocabulary for this project — entities, named processes, and status concepts with project-specific meaning. Seeded with core domain vocabulary, then accretes as ce-compound captures and refreshes learnings; direct edits are fine. Glossary only, not a spec or catch-all.

## Tag

A reusable label in the shared library that can be attached to multiple transactions.

Magic enrichment adds unmatched tag names to the transaction draft. Saving or confirming Combine resolves the names still selected to existing or newly created library tags.

## Magic enrichment

An action that uses source emails to suggest transaction details and fills the form draft for review before saving.

## Combine

The operation that consolidates two or more transactions with the same currency and account assignment into one transaction with their summed amount. All selected transactions can also be unassigned.
